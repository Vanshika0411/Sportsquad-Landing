# 🏟 SportsQuad – Sports Stadium Booking Platform

**Project Overview:**
SportsQuad is a **responsive web application** that allows users to quickly and easily book sports stadiums for various sports like Cricket, Football, and Badminton. This project is designed to provide a **smooth and professional booking experience**, with a clean UI, responsive layout, and live backend integration using MongoDB.

---

## 💡 Features

* **Hero Section:**
  Catchy landing section with heading, description, and call-to-action button to book a stadium instantly.

* **Features Section:**
  Highlights key functionalities: Easy Booking, Multiple Sports, and Responsive Design.

* **Booking Form:**
  Users can fill in their Name, select Sport, pick a Date, and **submit the form**.

  * Data is saved in **MongoDB** via backend API.
  * Success message appears instantly upon booking.

* **Responsive & Professional Design:**
  Works smoothly on **desktop, tablet, and mobile devices**. Clean layout and polished design for better user experience.

---

## ⚡ Tech Stack

* **Frontend:** React.js
* **Styling:** CSS (modern responsive design)
* **Backend:** Node.js + Express.js
* **Database:** MongoDB Atlas
* **API:** REST API for booking submission
* **Additional:** CORS for cross-origin requests

---

## 🚀 Installation & Setup

1. **Clone the repository:**

```bash
git clone https://github.com/<your-username>/sportsquad-landing.git
```

2. **Backend Setup:**

```bash
cd backend
npm install
# add .env file with MONGO_URI and PORT
node server.js
```

3. **Frontend Setup:**

```bash
cd ../
npm install
npm run dev
```

4. **Open the app in your browser:**

* Visit `http://localhost:5173` (or the port shown in terminal)
* Fill the booking form → submit → data saved in MongoDB
