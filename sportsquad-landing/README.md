# Sportsquad Stadium Booking Landing Page

This is a **simple responsive landing page** for a sports stadium booking platform built using **React + Vite**.  
It was developed as part of a web development internship assignment at **Sportsquad Private Limited**.

---

## 🧩 Features

- **Hero Section** with heading and Call-to-Action button  
- **Features Section** with 3 key features:
  - Easy Booking
  - Multiple Sports
  - Responsive Design
- **Basic Booking Form**
  - Name
  - Sport Type (Cricket, Football, Badminton)
  - Date
  - Submit button

- Fully **responsive** design (works on desktop and mobile)
